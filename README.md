# Pixel2World

An Iterative Stateful Multi-Agent System that converts 2D pixel maps into geometrically accurate, game-ready 3D terrain assets in Unity 6 with no manual modelling required.

> Status: In progress - implementation yet to be started

---

## Tech stack

- LangGraph (stateful agent orchestration)
- Llama 3.2-Vision (perception + quality critic)
- DepthAnything V2 (depth estimation model)
- FastAPI (REST communication bridge)
- Unity 6 (terrain output)
